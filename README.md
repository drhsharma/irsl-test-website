# IRSL Test Website

This is the first GitHub workflow test repository for:

**IRSL — Intelligent & Reconfigurable Structures Laboratory**  
BITS Pilani, Pilani Campus

## Purpose

This repository is currently for checking the workflow:

```text
ChatGPT → GitHub repository → GitHub Pages / live website
```

The design and content are temporary. Once this workflow is confirmed, the same structure can be improved into the final IRSL lab website.

## Current website sections

- Home
- Research themes
- People
- Publications
- Facilities
- Contact

## Suggested GitHub Pages setup

1. Go to repository **Settings**.
2. Open **Pages**.
3. Select **Deploy from a branch**.
4. Select branch **main** and folder **/root**.
5. Save.

Expected URL:

```text
https://drhsharma.github.io/irsl-test-website/
```

## Important note about private repository

The repository is private for now. For a completely free public lab website, the repository can later be made public before enabling GitHub Pages, or we can connect the repository to Cloudflare Pages later.
